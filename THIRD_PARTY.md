# Third-party software

## ChatGPT-Web2API

`chatgptproxy` uses ChatGPT-Web2API as its upstream browser/API transport.

- Project: https://github.com/Octo-Lex/ChatGPT-Web2API
- Package: `chatgpt-web2api`
- License: MIT

No ChatGPT-Web2API source code is copied into this repository. The package is installed as a dependency and invoked through its documented command-line and local HTTP interfaces.
